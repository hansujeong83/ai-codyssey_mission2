# Codyssey Mission 2 — Python 퀴즈 게임

26올인원 1기 미션 2의 Python 콘솔 퀴즈 게임 구현 저장소입니다.

## 주요 기능
- 기본 퀴즈 목록 조회 및 새 퀴즈 등록
- 문제 수를 선택해 퀴즈 실행
- 정답 판정과 점수 계산
- 퀴즈 및 플레이 기록 JSON 저장·불러오기
- 잘못된 입력과 손상된 저장 데이터에 대한 예외 처리

## 프로젝트 구성
- `main.py`: 퀴즈 모델, 게임 흐름, 저장 기능
- `test_main.py`: 모델·입력·저장·게임 흐름 자동 테스트
- `.gitignore`: Python 캐시 및 런타임 저장 파일 제외
- `SUBMISSION_STATUS.md`: 제출 전 점검 사항

## 실행 방법
Python 3.10 이상을 권장합니다.

```bash
python main.py
```

## 자동 테스트
프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python -m unittest -v
```

테스트는 퀴즈 데이터 검증, 입력 처리, JSON 저장 및 복구, 게임 진행 흐름을 확인합니다.

## 제출 전 확인
- 본인 환경에서 프로그램을 실행합니다.
- 퀴즈 추가·조회·플레이·점수·저장 기능을 직접 확인합니다.
- Git 브랜치, 커밋, 병합, clone 및 pull 미션은 실제 명령 수행 기록과 캡처를 별도로 확보합니다.
